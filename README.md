# 行程助手 CarTripAssistant

当前版本：**V3.2.0 / Build 3200**（iOS 16.0+）

版本一致性：云编译 IPA Info.plist、IPA 文件名、源码归档和 GitHub Artifacts 均使用 V3.2.0；Build 号 3200。

V2.5.3：在 V2.4.7 基础上同步 App、云编译、IPA、源码包和说明版本号；保留此前外观模式与轨迹回放修改。尚待云编译和真机验证。

历史调整：行程地图显示系统实时蓝点；区分红色行程起点与当前位置；单点轨迹提示；行程暂停或步行状态下仍保留有效 GPS 地图轨迹，但不把步行或手动休息期间的移动计入车辆里程。

注意：红色起点是**开始行程后第一个符合精度要求的 GPS 记录点**，不是实时位置；系统蓝点才代表当前定位。地图轨迹记录仍需真机验证。

深圳道路离线地图为单独下载的 MBTiles，不打包进 IPA。

V2.3.9：新行程开始时立即向 Core Location 请求新定位；首个有效 GPS 轨迹点立即持久化，防止刚开始行程后 APP 被关闭造成起点丢失。继续过滤行程开始之前的缓存定位。

V2.3.9：简化车辆里程累计：不再以系统步行识别作为 GPS 里程一票否决条件；有效定位移动速度门槛降低至 0.8 米/秒，保留手动休息、GPS 精度与异常跳点保护。后台与前台使用同一套累计逻辑。

V2.3.9：行程轨迹地图统一使用苹果原生地图底图作为 GPS 坐标参照，暂不叠加坐标基准未验证的第三方深圳 MBTiles（已安装地图文件不会删除）；轨迹更新不再强制重置用户手动放大的地图比例。保留 V2.3.3 简化里程累计逻辑。

V2.3.9：里程计算使用上次已计入里程的 GPS 定位作为累计锚点，避免连续小步长定位被永久丢弃；锚点过期、GPS 中断和手动休息时重置；轨迹采样由 30 秒/25–45 米调整为 15 秒/12–25 米。坐标漂移的根因仍需真实 GPS 数据验证。

V2.3.9：行驶中优先保存约每秒一个真实 GPS 点，关闭 5 米系统距离过滤；停车时仍抑制 GPS 抖动。系统不保证严格每秒回调，不补造坐标；保留 V2.3.5 里程累计修复。

V2.3.9：轨迹回放按 GPS 真实时间戳推进，1× 为实际时间、2×/5× 为加速；进度条改为时间轴，避免按固定点数跳跃。未收到的 GPS 点不会伪造成真实路线。

V2.3.9：轨迹页新增实时 GPS 与保存轨迹终点距离（米）、终点距今时间、实时定位精度诊断，用于定位后台轨迹终点偏移原因；保留逐秒采样与时间轴回放。

V2.3.9：修复诊断页读取 private CLLocationManager 导致的 Swift 编译错误；诊断数据改为 TripStore 已验证的最近 GPS 定位，和实际轨迹记录使用同一定位数据源。

V2.5.3：轨迹回放车辆标记与自动跟随、驾驶舱 UI 对比度优化；基于 main 最新源码构建，尚待云编译与真机验证。

V2.5.3：轨迹回放增加20×、30×、40×、50×与20/30/60秒整程快速浏览（默认30秒），轨迹页地图黑色提示胶囊改为主题适配浅色样式。待云编译和真机验证。

V2.5.3：轨迹回放改为全程地图固定视角，取消车辆自动跟随、自动缩放；车辆标记继续沿路线移动，保留20/30/60秒快速浏览。待云编译及真机验证。

V2.6.3 / Build 2603：工具页行程统计、停车识别、备份、诊断支持可记忆折叠；历史记录按日期折叠、展开后延迟渲染明细；首页收车按钮改为居中紧凑布局。GPS采集及里程算法保持不变。尚待云编译与真机验证。

V2.6.3 / Build 2603：修复行程分享卡「全天总里程」白字在浅色卡片上不可读的问题，改用自适应蓝色文字；GPS记录逻辑未改，停车漂移问题待后续专项修复。

V2.6.3 / Build 2603：停车GPS继续接收但不再按漂移持续追加轨迹；行驶时根据速度、位移及定位精度保留真实点；休息和步行不追加行驶轨迹。定位速度误报或低速挪车仍需真机验证，里程累计公式未改。

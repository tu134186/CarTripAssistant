# 行程助手 CarTripAssistant

当前版本：**V2.3.1 / Build 2301**（iOS 16.0+）

版本一致性：云编译生成的 IPA Info.plist、IPA 文件名、源码归档、GitHub Artifacts 均使用 V2.3.1；Build 号 2301。

本版调整：行程地图显示系统实时蓝点；区分红色行程起点与当前位置；单点轨迹提示；行程暂停或步行状态下仍保留有效 GPS 地图轨迹，但不把步行或手动休息期间的移动计入车辆里程。

注意：红色起点是**开始行程后第一个符合精度要求的 GPS 记录点**，不是实时位置；系统蓝点才代表当前定位。地图轨迹记录仍需真机验证。

深圳道路离线地图为单独下载的 MBTiles，不打包进 IPA。

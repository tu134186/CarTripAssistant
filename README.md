# 行程助手 CarTripAssistant

当前版本：**V2.3.5 / Build 2305**（iOS 16.0+）

版本一致性：云编译生成的 IPA Info.plist、IPA 文件名、源码归档、GitHub Artifacts 均使用 V2.3.5；Build 号 2305。

本版调整：行程地图显示系统实时蓝点；区分红色行程起点与当前位置；单点轨迹提示；行程暂停或步行状态下仍保留有效 GPS 地图轨迹，但不把步行或手动休息期间的移动计入车辆里程。

注意：红色起点是**开始行程后第一个符合精度要求的 GPS 记录点**，不是实时位置；系统蓝点才代表当前定位。地图轨迹记录仍需真机验证。

深圳道路离线地图为单独下载的 MBTiles，不打包进 IPA。

V2.3.5：新行程开始时立即向 Core Location 请求新定位；首个有效 GPS 轨迹点立即持久化，防止刚开始行程后 APP 被关闭造成起点丢失。继续过滤行程开始之前的缓存定位。

V2.3.5：简化车辆里程累计：不再以系统步行识别作为 GPS 里程一票否决条件；有效定位移动速度门槛降低至 0.8 米/秒，保留手动休息、GPS 精度与异常跳点保护。后台与前台使用同一套累计逻辑。

V2.3.5：行程轨迹地图统一使用苹果原生地图底图作为 GPS 坐标参照，暂不叠加坐标基准未验证的第三方深圳 MBTiles（已安装地图文件不会删除）；轨迹更新不再强制重置用户手动放大的地图比例。保留 V2.3.3 简化里程累计逻辑。

V2.3.5：里程计算使用上次已计入里程的 GPS 定位作为累计锚点，避免连续小步长定位被永久丢弃；锚点过期、GPS 中断和手动休息时重置；轨迹采样由 30 秒/25–45 米调整为 15 秒/12–25 米。坐标漂移的根因仍需真实 GPS 数据验证。
